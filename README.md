# Молекулярная динамика двумерного газа Леннарда-Джонса

Лабораторная работа №2 по курсу «Компьютерное моделирование».

Тема: интегрирование уравнений движения методом Верле и проверка
распределения скоростей Максвелла (в 2D — Рэлея).

## Структура

```
lj_md/          исходный код модели
tests/          тесты (pytest)
results/        графики и данные (не коммитятся)
```

## Установка

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

```
python -m lj_md.model
```

## Тесты

```
pytest
```
